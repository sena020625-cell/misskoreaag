# misskorea: 미쓰코리아 쇼츠 제작 자동화

유튜브 쇼츠 채널 **미쓰코리아**(@미쓰코리아K)의 영상 제작을 돕는 Claude Code 플러그인과 작업 화면입니다.
사람은 **영상 링크 고르기, 영상 파일 받기, 검수, 캡컷 편집**만 하고, 영상 읽기·대본·제목·설명란(출처)·음성·자막·캡컷 프로젝트 만들기는 자동으로 처리합니다.

```
 ① 소재 고르기        ② 대본 만들기             ③ 작업 화면                  ④ 캡컷
(노션 추천 / 직접)   (Claude 앱에서 한 번)    (start 화면, 클릭만)         (편집·내보내기)

 링크 + 제품명  ──▶  /misskorea:run   ──▶  검수 → 영상 넣기 → 음성 → 캡컷으로 보내기  ──▶  최종 편집
                    (Chrome으로 영상을 읽고
                     대본·제목·설명란 작성)
```

- 파일을 직접 열어 고칠 필요가 없습니다. 검수와 승인은 작업 화면에서 합니다.
- 각자 컴퓨터에서 각자의 Claude 구독으로 돌아갑니다. 서버는 없습니다. 음성(TTS)만 별도 TTS 서비스 크레딧을 씁니다.
- **사용 허락을 받은 영상만 수급하는 것이 전제**입니다. 이 도구는 허락 여부를 묻거나 기록하지 않습니다. 허락은 사람이 따로 관리하세요.

## 1. 준비물 (처음 한 번)

| 항목 | 설명 |
|---|---|
| Claude Code 데스크톱 앱 | 유료 플랜(Pro, Max, Team, Enterprise) 로그인 |
| Chrome + 확장 프로그램 **Claude in Chrome** | 링크로 영상 내용을 읽는 데 씁니다. 확장 프로그램을 설치하고 Claude와 같은 계정으로 로그인하세요 |
| Python 3.10 이상 | Windows: `winget install Python.Python.3.12`. 설치 후 앱과 터미널을 완전히 껐다 켭니다 |
| ffmpeg | Windows: `winget install Gyan.FFmpeg`. `ffmpeg -version`이 실행돼야 합니다 |
| Python 패키지 | `pip install requests python-dotenv PyYAML Pillow` |
| 타입캐스트 계정 | 더빙용 API 키와 **채널 고정 보이스 ID**. 상업적 사용 가능 여부는 요금제 약관을 확인하세요 |
| 캡컷(CapCut) 데스크톱 | 서식 견본으로 쓸 **기존 완성 프로젝트가 1개 이상** 있어야 합니다(아래 5장) |

## 2. 설치

Claude Code에서 아래 두 줄을 차례로 입력하고 앱을 다시 시작합니다.

```
/plugin marketplace add sena020625-cell/misskoreaag
/plugin install misskorea@misskorea-marketplace
```

입력창에 `/misskorea`를 치면 `/misskorea:run`, `/misskorea:batch`, `/misskorea:render`가 보여야 합니다. 이름 앞에 `misskorea:`가 붙은 형태가 정식 이름입니다.

**업데이트:** 저장소가 갱신되면 터미널에서 아래 두 줄을 실행하고 앱을 다시 시작합니다.

```
claude plugin marketplace update misskorea-marketplace
claude plugin update misskorea@misskorea-marketplace
```

### 작업 폴더 만들기

플러그인과 **작업 폴더는 따로**입니다. 영상과 결과물은 작업 폴더에 쌓이고, Claude 앱도 이 폴더에서 엽니다. 위치와 이름은 자유입니다.

```powershell
mkdir misskorea-work
cd misskorea-work
mkdir input, output
```

작업 폴더에 `.env`를 만듭니다(팀이 정한 보이스 ID를 모두 똑같이 씁니다).

```
TTS_PROVIDER=typecast
TYPECAST_API_KEY=여기에_본인_API_키
TYPECAST_VOICE_ID=tc_로_시작하는_보이스_ID
TYPECAST_MODEL=ssfm-v30
TYPECAST_LANGUAGE=kor
```

- 보이스 ID는 이름(예: 혜원)이 아니라 `tc_`로 시작하는 값입니다. 모르면 `.env`를 만든 뒤 `python <플러그인 폴더>/scripts/typecast_voices.py 혜원`으로 찾습니다(조회만 하며 크레딧이 들지 않습니다). `<플러그인 폴더>`는 `~/.claude/plugins/cache/misskorea-marketplace/misskorea/<버전>`입니다.
- ElevenLabs를 쓰려면 `TTS_PROVIDER=elevenlabs`와 `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`를 채웁니다. 모든 항목은 플러그인의 `templates/.env.example`에 설명이 있습니다.
- **API 키는 본인 것만 쓰고 절대 공유·커밋하지 마세요.**

### 작업 화면 실행 파일 복사

플러그인 폴더의 `templates/작업화면.bat`을 **작업 폴더에 복사**합니다. 이제 이 파일을 더블클릭하면 작업 화면이 열립니다.

## 3. 하루 작업 흐름

### ① 소재 고르기: 링크 + 제품명

편집할 제품과 영상 링크를 정합니다. 제품 하나에 영상은 **2~3개**를 모으세요(컷마다 섞어 편집합니다). 소재는 직접 찾거나, 매일 아침 노션 추천 목록에서 가져옵니다(5장).

### ② 대본 만들기: `/misskorea:run`

작업 폴더에서 Claude 앱을 열고 아래 형식으로 붙여 넣습니다. 링크는 한 줄에 하나, 제품명은 `제품명:` 줄입니다. **제품명은 항상 직접 적어 주세요.** 영상 속 제품을 추측하지 않습니다.

```
/misskorea:run
https://www.tiktok.com/@albina/video/7532577426111515922
https://www.tiktok.com/@albina/video/7641618564272753941
제품명: 스킨1004 마다가스카르 센텔라 라이트 클렌징오일
```

- 제품이 여러 개면 빈 줄(또는 `---`)로 나눕니다.
- 선택 줄: `공식몰: <주소>`, `훅: <첫 줄 문구>`, `강조: <꼭 넣을 특징>`, `메모: <영상에서 일어나는 일>`.
- Claude가 **Chrome으로 링크를 차례로 열어** 계정, 캡션, 길이, 장면(5곳)을 읽고, 공식몰을 찾아 대본 2버전, 제목 후보, 상단 타이틀, 설명란(출처 포함)을 `output/날짜/번호/`에 저장합니다. 영상은 내려받지 않습니다.
- Chrome이 연결돼 있지 않으면 영상 분석 없이 공식몰 정보만으로 만들고 "영상 내용을 확인하지 못함"으로 표시합니다.

**영상 읽기의 한계:** 소리(대사)는 읽을 수 없습니다. 화면, 캡션, 해시태그만 근거로 쓰고 소리는 "미확인"으로 남깁니다. 영상 속 제품이 제품명과 맞는지 불확실하면 검수 메모에 표시합니다. 로그인 창이나 CAPTCHA가 뜨면 그 링크는 직접 확인해야 합니다.

### ③ 작업 화면에서 검수하고 만들기

`작업화면.bat`을 더블클릭합니다(창을 닫으면 화면도 꺼집니다). 왼쪽에서 제품을 고르면 4단계가 보입니다.

| 단계 | 하는 일 |
|---|---|
| 1. 대본 검수 | 맨 위의 **확인 못 한 것**, **심의 주의 표현**을 먼저 읽습니다. 버전 1·2의 문구를 줄별로 고치고, 쓸 버전을 고르고, 상단 타이틀을 확인합니다. 제목 후보와 설명란은 복사 버튼으로 가져갑니다. 끝나면 **검수 완료**를 누릅니다 |
| 2. 영상 넣기 | 제작자에게 받은 영상 파일(mp4 등)을 끌어다 놓습니다. 2~3개를 넣으면 컷마다 돌아가며 섞입니다 |
| 3. 음성 만들기 | 검수 완료 후 버튼 하나로 한국어 음성을 만듭니다(타입캐스트 크레딧 사용). 바로 들어볼 수 있습니다 |
| 4. 캡컷으로 보내기 | 서식 견본(기존 캡컷 프로젝트)을 고르고 누르면 새 캡컷 프로젝트가 만들어집니다 |

- 문구를 고치면 검수 완료가 풀립니다. 고친 뒤에는 다시 **검수 완료**를 눌러야 음성 단계로 갑니다.
- 승인하려면 선택한 버전이 **4~7줄, 예상 16~30초**여야 합니다.
- **캡컷은 완전히 종료한 상태에서** 4단계를 누르세요. 켜져 있으면 막힙니다.

### ④ 캡컷에서 편집

캡컷을 열면 프로젝트 목록 맨 앞에 `미쓰코리아_제품명_날짜`가 있습니다. 컷, 타이틀, 자막, 음성이 들어 있는 상태에서 마무리 편집하고 내보냅니다. 업로드는 직접 합니다(자동 업로드는 없습니다).

## 4. 화면 규칙 (유튜브 프레임 안에 들어오게)

- **자막:** 한 화면에 **10자(공백 포함) 이하**로 나뉘어 차례로 나옵니다. 캡션 문장은 길게 써도 편집 단계에서 자동으로 나뉩니다.
- **상단 타이틀:** 각 줄 **10자 안팎, 최대 13자**. 13자를 넘으면 검수 완료와 캡컷 만들기가 막힙니다.
- **싱크:** 타입캐스트가 돌려주는 **글자별 시간**으로 자막 구간을 정합니다. 시간이 없는 음성(시험용 무음 등)은 글자 수에 비례해 나눕니다.
- **영상 컷:** 캡션 줄 경계마다 컷을 나누고, 넣은 영상들을 돌려가며 씁니다. 원본 소리는 0입니다.
- 위치, 글꼴, 크기, 색은 **서식 견본으로 고른 캡컷 프로젝트의 것을 그대로** 따릅니다. 바꾸려면 다른 견본을 고르세요.

## 5. 캡컷 연결 자세히

- 새 프로젝트는 기존 프로젝트 하나를 **서식 견본**으로 삼아 만들어집니다. 견본은 읽기만 하고 **바뀌지 않습니다.**
- 견본으로 쓸 수 있는 프로젝트(영상 트랙 위에 글자 트랙 3개와 음성 트랙이 있는 것)만 목록에 나옵니다. 안 되는 프로젝트는 목록에서 빠집니다.
- 만들 때 캡컷 프로젝트 목록 파일(`root_meta_info.json`)에 항목을 추가합니다. 추가하기 전에 작업 폴더의 `backup/`에 백업합니다.
- 캡컷 프로젝트 형식은 **캡컷 내부 형식**이라 캡컷이 업데이트되면 달라질 수 있습니다. 새 버전으로 바꾼 뒤에는 프로젝트가 정상으로 열리는지 먼저 확인하세요.
- 만든 프로젝트를 지우고 싶으면 캡컷을 끈 뒤 프로젝트 폴더를 지우고, `backup/`의 목록 파일을 되돌립니다.

## 6. 매일 아침 소재 추천 (선택)

Claude의 예약 작업이 매일 아침 TikTok에서 K-뷰티 트렌드를 찾아 **제품당 영상 2~3개**를 노션 표에 올립니다. 한 줄이 곧 `/misskorea:run`의 입력(제품명 + 링크)입니다. 표의 `상태`(추천/선택/제작중/완료/패스)로 진행을 관리합니다.

- 앱이 열려 있고 Chrome이 켜져 있는 컴퓨터에서 돌아갑니다. 앱이 닫혀 있으면 다음에 앱을 열 때 실행됩니다.
- 영상은 내려받지 않고 링크만 모읍니다. 제품을 특정하지 못한 영상은 "확인 필요"에 적습니다.
- 처음 설정은 Claude 앱에서 "노션 추천 표를 만들고 매일 아침 예약 작업을 걸어줘"라고 요청하면 됩니다.

## 7. 이전 방식 (CSV 일괄 처리)

링크 없이 공식몰 주소로 대본을 만들고 ffmpeg로 완성본(`final.mp4`)까지 뽑는 방식도 남아 있습니다.

| 명령어 | 하는 일 |
|---|---|
| `/misskorea:batch` | `input/batch.csv`의 모든 줄에 대해 대본 패키지를 만들고 요약표를 만든다 |
| `/misskorea:render` | 승인된 대본의 TTS 더빙 → 자막 → 렌더링으로 `final.mp4`를 만든다 |

- CSV 헤더: `id,제품명,공식몰URL,원본링크,원본메모,훅,강조포인트,크리에이터,영상링크,사용허락`(UTF-8). `id`는 영상 파일 이름과 같아야 합니다(`001` → `input/videos/001.mp4`).
- 이 방식에는 **사용 허락 기록 확인**이 남아 있습니다. `사용허락` 칸에 근거를 적어야 음성과 렌더링이 진행됩니다(`python <플러그인 폴더>/scripts/permission.py set 001 --value "Y 날짜 방법"`). `/misskorea:run`과 작업 화면에서는 이 확인을 건너뜁니다.
- 화면 모양(ffmpeg 렌더)은 작업 폴더의 `config/template.yaml`로 덮어쓸 수 있습니다. 자막은 한 줄 10자(`max_chars_per_line: 10`)가 기본입니다.

## 8. 자주 나는 오류와 해결

| 증상 | 원인과 해결 |
|---|---|
| `/misskorea:run`이 목록에 없다 | 플러그인이 구버전입니다. 위 업데이트 두 줄을 실행하고 앱을 다시 시작하세요 |
| 영상 분석이 안 되고 "Chrome 연동 필요"가 나온다 | Chrome 확장 "Claude in Chrome" 설치와 같은 계정 로그인, Chrome이 켜져 있는지 확인하세요. API 키로만 로그인한 경우에는 연동이 꺼집니다 |
| 링크를 열었는데 빈 화면 | TikTok은 열고 5초쯤 기다려야 합니다. 로그인이나 CAPTCHA가 떠 있으면 직접 처리한 뒤 다시 실행하세요 |
| 작업 화면이 안 열린다 | `작업화면.bat` 창에 나온 안내를 읽으세요. Python 미설치, 플러그인 미설치가 대부분입니다. 이미 열려 있으면 8765 포트가 사용 중일 수 있으니 이전 창을 닫으세요 |
| 화면에서 "먼저 검수 완료를 눌러 주세요" | 1단계에서 **검수 완료**를 눌러야 음성이 만들어집니다 |
| "예상 길이가 N초입니다" | 선택한 버전이 16~30초가 되도록 문구를 줄이거나 늘리세요 |
| "상단 타이틀은 10자 안팎..." | 타이틀 한 줄이 13자를 넘었습니다. 줄여서 다시 저장하세요 |
| "캡컷이 켜져 있습니다" | 캡컷을 **완전히 종료**(작업 표시줄 트레이 포함)한 뒤 다시 누르세요 |
| 서식 견본 목록이 비어 있다 | 쓸 수 있는 캡컷 프로젝트가 없습니다. 영상 위에 글자 3줄(타이틀 2줄, 자막)과 음성 트랙이 있는 완성 프로젝트를 1개 만들어 두세요 |
| "영상이 너무 짧습니다" | 넣은 영상 하나가 어느 줄 길이보다 짧습니다. 더 긴 영상을 넣거나 영상을 더 추가하세요 |
| 캡컷에서 프로젝트가 안 보이거나 비어 있다 | 캡컷을 껐다 켜 보세요. 그래도 안 되면 작업 폴더의 `capcut_out/`에 만들어진 폴더와 함께 알려 주세요 |
| 자막이 목소리와 어긋난다 | 글자 시간이 없는 음성인지 확인하세요(`output/날짜/번호/timing.json`에 줄마다 `chars`가 있어야 합니다). 타입캐스트 오류가 났다면 `.env`를 `TTS_PROVIDER=per_line`, `PER_LINE_BACKEND=typecast`로 바꿔 보세요(줄 단위 싱크) |
| `python`을 찾을 수 없다 | Python 설치 후 앱과 터미널을 완전히 껐다 켜세요. Windows에서는 `py -3`로도 시도합니다 |
| `ModuleNotFoundError` (requests, yaml, PIL, dotenv) | `pip install requests python-dotenv PyYAML Pillow` |
| `ffmpeg를 찾을 수 없습니다` | ffmpeg 설치 후 앱과 터미널을 다시 엽니다 |
| 타입캐스트 오류 401 / 404 | API 키(`TYPECAST_API_KEY`) 또는 보이스 ID(`tc_`로 시작)가 틀렸습니다 |
| 타입캐스트 오류 402 / 429 | 크레딧 부족 / 요청 한도 초과입니다. 요금제를 확인하고 잠시 뒤 다시 하세요 |
| 타입캐스트 오류 422 | 합성할 수 없는 문구입니다. 이모지나 특수 기호를 빼세요 |
| 발음이 이상하다 | 영문·긴 제품명이 흔한 원인입니다. 대본 문구를 TTS가 읽기 쉽게 고치세요. 문구를 고치면 음성은 다시 만들어집니다. "스킨1004" 같은 표기는 읽는 방식을 팀이 정하세요 |

## 9. 비용이 생기는 곳

| 단계 | 비용 |
|---|---|
| 영상 읽기와 대본 생성(`/misskorea:run`) | 각자의 Claude 사용량. 영상마다 장면 화면 5장을 읽으므로 영상이 많을수록 늘어납니다 |
| 음성(작업 화면 3단계) | 타입캐스트(또는 ElevenLabs) 크레딧. 영상 1개당 대략 150~300자입니다. 같은 문구는 다시 합성하지 않습니다 |
| 캡컷 프로젝트, 자막 | 없음(내 컴퓨터) |

## 10. 지켜야 할 것

- 영상은 **사용 허락을 받은 것만** 씁니다. 이 도구는 영상을 내려받지 않습니다(링크만 읽습니다). 영상 파일은 제작자에게 받은 것을 직접 넣으세요.
- 영상 속 문구는 **확인된 사실**만 씁니다. 판매량·수상·수치를 만들어 넣지 않습니다. 검수 화면 맨 위의 "확인 못 한 것"을 꼭 읽으세요.
- 협찬·광고 표시가 있는 영상은 설명란 표기가 필요한지 팀이 판단하세요(검수 메모에 알립니다).
- 심의 표현(단정·절대 표현, 기능성 미확인 효능)은 `skills/misskorea-script/references/compliance.md`에 정리돼 있습니다.
- 업로드 전에 공식몰의 **품절·판매 중단 표기**를 확인하세요.
- Chrome 읽기는 좋아요·팔로우·댓글 같은 계정 활동을 하지 않습니다.

## 11. 개발·관리자 메모

```
misskorea/
├─ .claude-plugin/{plugin.json, marketplace.json}   저장소 자체가 마켓플레이스
├─ commands/{run.md, batch.md, render.md}           run: 링크+제품명 → 영상 읽기 → 대본
├─ skills/misskorea-script/                         대본 생성 스킬 + references(스타일·심의·스키마)
├─ app/{server.py, index.html}                      작업 화면(표준 라이브러리만, 127.0.0.1 전용, 토큰 인증)
├─ scripts/{tts.py, subtitle.py, capcut_draft.py, render.py, source_credit.py, permission.py, fetch_source.py, typecast_voices.py, common.py, tts_providers/}
├─ config/template.yaml                             ffmpeg 렌더 화면 모양 기본값
├─ assets/fonts/                                    폰트와 라이선스
├─ templates/{batch.csv, .env.example, 작업화면.bat}
├─ start.bat                                        저장소에서 바로 화면 실행(작업 폴더 = 저장소의 상위 폴더)
└─ tests/                                           python -m unittest discover -s tests
```

- **작업 화면**: `app/server.py --workdir <작업 폴더>`. `MISSKOREA_TTS_PROVIDER=mock`이면 무음 음성으로 시험한다(크레딧을 쓰지 않음).
- **캡컷 초안 생성**: `python scripts/capcut_draft.py <id> --date YYYYMMDD --workdir . --template <견본 프로젝트> --videos a.mp4 b.mp4 --out-dir capcut_out`. 먼저 `capcut_out/`에 만들어 검증하고, `--install`을 붙이면 캡컷 프로젝트 폴더로 복사하고 목록에 등록한다. 캡컷은 꺼 둔다. 자막은 `subtitle.wrap_spans`로 10자씩 나누고 `chars` 타이밍으로 싱크를 맞춘다.
- **출처 자동 표기**: `source_credit.py apply`(링크 1개), `apply-many`(여러 개).
- **TTS 공급자 추가**: `scripts/tts_providers/`에 `TTSProvider`를 상속한 클래스를 만들고 `__init__.py`의 `PROVIDERS`에 등록한다. `TTS_PROVIDER=mock`은 시험용이며 실제 영상에는 쓰지 않는다.
- **버전 올리기**: `.claude-plugin/plugin.json`과 `marketplace.json`의 `version`을 같이 올린 뒤 푸시한다. 설치 폴더 이름(`.../misskorea/<버전>`)으로 `작업화면.bat`이 가장 뒤의 폴더를 찾으므로, 버전 번호는 문자열 순서로도 커지도록 유지한다(예: `0.9.0` 다음은 `0.10.0`이 아니라 `1.0.0`).
- **로컬 시험**: `claude --plugin-dir <이 폴더>`로 설치 없이 불러올 수 있다.
- **다른 컴퓨터에서 테스트**: 설치, 폴더 복사, 격리 설치 방법은 [docs/TESTING.md](docs/TESTING.md)에 있다.
- 알려진 한계: Chrome 영상 읽기는 소리를 읽지 못하고, 캡컷 프로젝트 형식은 캡컷 버전에 따라 달라질 수 있다.
