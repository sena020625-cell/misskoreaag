# misskorea-script

해외에서 화제가 된 K-뷰티 제품을 16~30초 쇼츠로 소개하는 대본 패키지를 만든다.
영상은 해외 크리에이터 원본(사용 허락 확보) + 한국어 TTS 더빙 + 하단 노란 자막 + 상단 고정 타이틀 2줄로 구성된다.

## 먼저 읽을 참고 문서

작성 전에 아래 세 파일을 모두 읽는다. 이 스킬 폴더 기준 경로다.

- `references/style-guide.md`: TTS 캡션 스타일, 훅 패턴, 리듬 변주, 예시
- `references/compliance.md`: 화장품 광고 심의 규칙(금지 표현과 대체 표현)
- `references/output-schema.md`: script.json 스키마, script.md 양식, 설명란 템플릿, 해시태그 규칙

## 입력

| 항목 | 필수 | 설명 |
|---|---|---|
| 제품명 | O | 한글 제품명 |
| 공식몰 상세페이지 URL | O | 사실 확인의 1차 근거 |
| 원본 영상 링크 | 선택 | 참고용. 영상을 내려받거나 스크래핑하지 않는다 |
| 원본 메모 | 선택 | 원본 영상에서 무슨 일이 일어나는지 팀원이 적은 내용 |
| 훅 | 선택 | 원하는 첫 줄. 있으면 버전 1의 첫 줄에 쓴다(심의 위반이면 완화하고 메모에 남긴다) |
| 강조 포인트 | 선택 | 꼭 넣고 싶은 특징 |
| 크리에이터 | 선택 | 설명란 마지막 `📷I` 줄에 쓴다. 없으면 그 줄을 빼고 검수 메모에 적는다 |
| 출력 폴더 | 선택 | 지정되면 파일로 저장한다(아래 "출력 방식") |

## 절차

### 1. 사실 확인

1. 공식 상세페이지를 WebFetch로 읽는다. 아래 항목을 찾아 기록한다.
   - 제품명(한글/영문), 브랜드(한글/영문), 영문 제품 라인명
   - 주요 성분
   - 기능성 표기(식약처 기능성화장품 심사/보고 여부 포함)
   - 사용법
   - 인체적용시험 수치(원문 그대로, 시험 조건 포함)
2. 항목이 비었거나 페이지가 이미지뿐이면 해외 판매처(세포라, 올리브영 글로벌, YesStyle 등)와 브랜드 글로벌 공식 사이트를 WebSearch로 찾아 보완한다. 보완한 항목마다 출처 URL을 남긴다.
3. 그래도 확인되지 않은 항목은 **쓰지 않고** 검수 메모의 "확인 못 한 것"에 적는다. 추측으로 채우지 않는다.
4. 원본 메모는 "영상에서 일어나는 일"을 구성하는 재료로만 쓴다. 효능이나 수치 주장은 근거를 확인한 것만 쓴다.
5. 페이지에 품절, 단종, 판매 중단 표기가 있으면 `review.notes`에 "품절 표기" 또는 "SOLD OUT"이라는 단어를 넣어 알리고 `needs_review`를 `true`로 한다. 영상 업로드 전에 팀이 판단할 사항이다.

### 2. 확인된 사실만 사용

- 판매량, 순위, 수상 이력, 해외 반응, 수치는 출처에서 확인된 것만 쓴다. 지어내지 않는다.
- 해외 반응 표현은 원본 영상에서 확인되는 범위 안에서만 쓴다. 예: "외국에서 난리 난"은 사용자가 준 훅이나 원본 메모가 근거일 때만 쓴다. 근거가 없으면 영상 자체의 장면(무엇을 하는가)을 중심으로 쓴다.
- 인체적용시험 수치를 쓰면 검수 메모에 "영상 하단에 '인체적용시험 결과, 개인차 있음' 표기 필요"를 반드시 남긴다.

### 3. 산출물 작성

1. **TTS 캡션 2버전**: 각 4~7줄, 읽었을 때 16~30초. 스타일은 `style-guide.md`를 따른다. 두 버전은 서로 다른 훅 패턴과 전개로 쓴다.
2. **첫 줄 대체 훅 3개**
3. **제목 후보 4~5개** + 1순위와 그 이유 한 줄
4. **상단 타이틀 2줄**: 첫 줄은 흰 글씨, 둘째 줄은 초록 박스 강조(10자 안팎, 짧게)
5. **설명란**: `output-schema.md`의 템플릿과 해시태그 규칙
6. **검수 메모**: 사용한 근거(출처 URL), 확인 못 한 것, 심의 위험 표현

### 4. 자체 점검(저장 전에 반드시)

- [ ] 캡션에 근거 없는 수치, 판매량, 수상, 순위가 없다
- [ ] `compliance.md` 금지 표현이 없다(캡션, 제목, 타이틀, 설명란 전부)
- [ ] 두 버전 모두 4~7줄이고 `est_seconds`(= 줄을 이어 붙인 글자 수, 공백 포함 ÷ 7.5, 소수 첫째 자리)가 16~30초 안이다. 손으로 어림하지 말고 계산해서 쓴다
- [ ] 연속된 줄이 같은 어미로 끝나지 않는다. 줄 끝맺음 부호가 다양하다
- [ ] 마무리 멘트가 "미쳤네요"로 고정되지 않았다
- [ ] TTS가 잘못 읽을 줄임말과 기호가 없다(착붙, 꾸안꾸 등은 풀어 쓴다)
- [ ] 제품명이 정확하다(상세페이지 표기와 일치)
- [ ] 검수 메모의 "확인 못 한 것"과 심의 항목이 빠짐없이 적혀 있다

## 출력 방식

- **출력 폴더가 지정된 경우**(예: `/misskorea:batch` 호출): 폴더에 `script.json`(기계용)과 `script.md`(사람 검수용)를 저장한다. 스키마와 양식은 `references/output-schema.md`를 따른다. 저장 후 한 줄로 결과(id, 1순위 제목, 검수 필요 여부)만 보고한다.
- **지정되지 않은 경우**(대화에서 직접 요청): `script.md` 양식 그대로 대화에 출력하고, 파일 저장 여부를 묻는다.

`script.json`의 `approved`는 항상 `false`로 시작한다. 사람이 검수하고 `true`로 바꿔야 렌더링 대상이 된다.

## 하지 않을 것

- 틱톡·인스타그램 영상 다운로드, 스크래핑
- 확인되지 않은 수치, 판매량, 수상 이력 작성
- 크리에이터 이름 추측
