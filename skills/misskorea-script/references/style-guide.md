# TTS 캡션 스타일 가이드

## 길이 기준

- 줄 수: 버전마다 4~7줄
- 목표 길이: 읽었을 때 16~30초
- 글자 수 기준(공백 포함): 약 90~160자. 한국어 TTS는 줄 사이 쉼을 포함해 초당 5~5.5자로 읽는 것으로 가정해 `est_seconds = 글자수 / 5.5`로 추정한다. 실제 길이는 TTS 단계에서 확정된다.
- 한 줄은 대체로 12~30자. 너무 길면 자막이 3줄 이상으로 쪼개진다.

## 구조

1. **첫 줄: 질문형 훅**. 아래 패턴 중 하나를 쓴다.
   - "한 여자가 ~하고 있는데요?"
   - "~에도 ~를 바른다고요?"
   - "~했더니 ~라고?"
   - "외국에서 난리 난 ~"
2. **둘째 줄 이후**: 반전 또는 결과 → 제품명 공개 → 감탄 마무리
   - 제품명 공개 문형: "바로 [브랜드]의 [제품명]인데요" (변주 가능: "[브랜드]의 [제품명]인데요,")
   - 마무리는 감탄이되 매번 같지 않게 한다.

## TTS 리듬 변주

- 줄마다 끝맺음을 다르게 한다. `?!` / `!!` / `.` / `…` 를 돌려 쓴다.
- 같은 어미(예: "~요" "~데요")를 연속 두 줄에 쓰지 않는다.
- 짧은 나열형 줄을 섞는다. 예: "잡티, 모공, 홍조까지."
- "미쳤네요"로 마무리를 반복하지 않는다. 변주 예: "이건 진짜 써봐야 해요!", "한국 뷰티, 역시 다르네요…", "이 조합은 반칙 아닌가요?!", "한 번 보면 계속 생각나요.", "괜히 화제가 아니었어요."

## TTS 발음 주의

- 줄임말·신조어는 풀어 쓴다: "착붙" → "착 달라붙어요", "꾸안꾸" → "꾸민 듯 안 꾸민 듯"
- 영문·기호가 섞인 제품명이 TTS에서 어색하게 읽힐 수 있으면 검수 메모에 "발음 확인 필요"라고 남긴다. 임의로 한글 음차를 만들지 않는다(음차는 팀이 정한다).
- 괄호, 슬래시, 이모지는 캡션에 쓰지 않는다.
- 숫자는 TTS가 읽는 방식을 고려해 쓴다(예: "24시간"). 근거 있는 수치만 쓴다.

## 훅 패턴 활용 팁

- 원본 영상의 이상한/의외의 장면에서 시작하면 반전을 만들기 쉽다(원본 메모 활용).
- 효능 단정은 훅에 쓰지 않는다. 장면, 질감, 사용 방식, 의외성으로 끈다.
- 사용자가 훅을 지정했으면 버전 1의 첫 줄에 쓰고, 버전 2는 다른 패턴으로 쓴다.

## 예시 (이 톤을 따를 것)

```
한 여자가 피부를 긁어내고 있는데요?!
알고 보니… 패치를 떼어내는 거였어요!
얇아도 너무 얇아서, 위에 화장을 해도 티가 하나도 안 나요.
심지어 입술 위에 붙여도 감쪽같다니까요?!
닥터멜락신의 S-ZINC 제로핏 블레미쉬 스팟 패치인데요,
진짜 한국 기술 미쳤네요…!!
```

관찰 포인트: 끝맺음이 `?!` → `!` → `.` → `?!` → `,` → `…!!`로 모두 다르다. 반전 → 특징 → 제품명 → 감탄 순서다.

## 상단 타이틀 2줄

- 1줄(흰 글씨): 해외 반응 또는 상황 요약. 예: "해외에서 핫한 한국 크림"
- 2줄(초록 박스): 강조 키워드, 10자 안팎. 예: "BEFORE → AFTER"
- 근거 없는 "1위", "완판", "해외 난리"는 쓰지 않는다. 원본 영상이나 출처로 뒷받침되는 표현만 쓴다.

## 제목 후보

- 4~5개. 쇼츠 제목으로 짧고 호기심을 유발하게 쓴다.
- 1순위를 고르고 이유를 한 줄로 적는다(예: "훅 장면이 제목에 그대로 담겨 클릭 유도가 가장 명확함").
- 해시태그는 제목에 넣지 않는다(설명란에 넣는다).
