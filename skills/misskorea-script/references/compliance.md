# 화장품 광고 심의 규칙

캡션, 제목, 상단 타이틀, 설명란 전부에 적용한다. 이 문서는 팀의 작업 규칙이며 법률 자문이 아니다. 애매하면 검수 메모의 "심의 위험 표현"에 올리고 사람이 판단하게 한다.

## 1. 단정·절대 표현 금지

단정하거나 절대적인 표현은 쓰지 않는다. 완화 표현으로 바꾼다.

| 금지 | 대체 예시 |
|---|---|
| 완벽, 완벽하게 | 깔끔하게, 감쪽같이 |
| 100%, 무조건, 반드시 | (삭제) 또는 "대부분", "꽤" |
| 즉시 제거, 바로 사라짐 | 싹, 감쪽같이 |
| 영구, 평생 | (삭제) |
| 최고, 1위, 최초, 유일 | 근거 있는 경우만, 출처와 함께 검수 메모에 기록 |
| 부작용 없음, 안전 보장 | (삭제) |

## 2. 기능성 등록이 확인되지 않은 효능 금지

기능성 화장품 심사/보고가 상세페이지나 공식 자료에서 확인되지 않은 효능은 쓰지 않는다.

| 금지 | 대체 예시 |
|---|---|
| 여드름 치료, 여드름 제거 | 트러블 케어, 진정 |
| 탈모 개선, 발모 | 모근 케어, 두피 케어 |
| 주름 개선 (기능성 미확인) | 탄력, 촘촘한 느낌 |
| 미백 (기능성 미확인) | 맑아 보이는, 톤 케어 |
| 염증 완화, 치료, 재생, 흉터 제거 | 진정, 보습 |
| 모공 축소, 지방 분해, 살 빠짐 | 모공 케어, 매끈한 피부결 |

기능성 표기가 상세페이지에 명시된 항목(예: 식약처 심사/보고 완료)은 그 문구 범위 안에서만 쓰고, 근거를 검수 메모에 남긴다.

## 3. 인체적용시험 수치

- 시험 수치는 상세페이지나 공식 자료에서 확인된 원문 그대로만 쓴다. 조건(기간, 인원, 부위)을 바꾸지 않는다.
- 수치를 쓰면 검수 메모에 아래 문구를 반드시 남긴다.
  > 영상 하단에 '인체적용시험 결과, 개인차 있음' 표기 필요
- `script.json`의 `review.needs_test_disclaimer`를 `true`로 한다.

## 4. 기타 주의

- 의약품 오인 표현 금지: 치료, 처방, 완치, 의학적 효과
- 타사 제품 비교·비방 금지
- 해외 반응, 판매량, 수상은 출처가 있을 때만 쓴다(출처가 없으면 쓰지 않는다)
- 전후 비교 연출(BEFORE→AFTER)은 원본 영상에서 실제로 보이는 것만 말한다. 효과를 보장하는 말투를 쓰지 않는다

## 검수 메모 기록 방식

위험 표현이 있거나 완화한 경우 `review.compliance_flags`에 `{text, issue, fix}`로 남긴다.

- `text`: 문제가 된 또는 완화 전 표현
- `issue`: 왜 위험한지(예: 절대 표현, 기능성 미확인 효능)
- `fix`: 실제로 쓴 대체 표현. 삭제했으면 "삭제"
